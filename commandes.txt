Pour le bootstrap, l'ordre complet avant le premier run est :

    # 1. Créer les dossiers data/
        python -c "from src.config.settings import ensure_directories; ensure_directories()"

    # 2. Créer la base de données (si DB active)
        python -m src.bootstrap.create_database

    # 3. Créer les schémas bronze/silver/gold (si DB active)
        python -m src.bootstrap.create_schemas
        python -m src.bootstrap.create_schemas --db duckdb

    # 4. Lancer le pipeline
        python -m src.pipelines.run_bronze

Lancer le pipeline
    python -m src.bronze.extract_indicators
    python -m src.pipelines.run_bronze


Lancer le pipeline with option BD
